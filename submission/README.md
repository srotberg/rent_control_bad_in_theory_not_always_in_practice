## What is in each file

- **Manuscript PDF**: the final paper, compiled from the source files.
- **Source files zip**: the manuscript `.tex`, the appendix `.tex`, one `.tex` file per table (`_Table_1` to `_Table_6`), the bibliography (`.bib`, compiled `.bbl`, and the `aer.bst` style), Figure 1 and the two panels of Figure 2 (`_Figure_2a`, `_Figure_2b`) as vector EPS (the artwork) and vector PDF (so the `.tex` compiles directly with pdfLaTeX), and the compiled PDF.
- **Replication files zip**: `EEREV-D-26-00102R2_ReadMe.pdf`, `code/`, `data/`, `outputs/`, `plots/`.
- **Highlights**: five bullet points (at most 85 characters each) summarising the paper, as encouraged by the Guide for Authors. Optional; check the wording before uploading.
- **Revision Notes 2**: point-by-point response to the editor's letter, how the package meets the replication policy for simulation papers, and the list of corrections made while preparing the files.

The editable text of the revision notes is in `writing/submission_sources/`.
